# Tokens

Semantic names only. See [design-system](./design-system) for the full spec.

## Colors

| Token                                | Role                |
| ------------------------------------ | ------------------- |
| `--color-primary` / `--color-accent` | Main CTA (朱)       |
| `--color-secondary`                  | Muted / outline     |
| `--color-success`                    | Positive (若緑)     |
| `--color-error`                      | Danger (蘇芳)       |
| `--color-warning`                    | Caution (山吹)      |
| `--color-info`                       | Neutral info (青磁) |
| `--color-surface`                    | Cards, panels       |
| `--color-foreground`                 | Primary text        |
| `--color-muted`                      | Secondary text      |

## Spacing (MA-based)

`--space-2`, `--space-4`, `--space-6`, `--space-8`, `--space-12`, `--space-16`, `--space-24`, `--space-32`, `--space-48`

## Motion

| Token               | Value    |
| ------------------- | -------- |
| `--duration-fast`   | 150ms    |
| `--duration-normal` | 200ms    |
| `--duration-slow`   | 300ms    |
| `--ease-out`        | ease-out |

## Keyframes

- `ui-fade-in` / `ui-fade-out` — Enter/leave
- `ui-scale-in` — Scale transition
- `ui-breathe` — Subtle pulse
